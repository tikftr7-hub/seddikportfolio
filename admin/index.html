Connect to GitHub

Your site's content lives in the GitHub repo. Saving here commits to it, and Vercel publishes the change in about 30 seconds.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → seddikportfolio
  3. Permissions → Repository → Contents: Read and write
  4. Generate, copy the token and paste it below
